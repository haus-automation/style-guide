# Style-Guide

## Farben

| Name       | Hex       | Verwendung       |
|------------|-----------|------------------|
| Orange     | `#e2671f` | Akzent, CTA      |
| Hellgrau   | `#7d7d7d` | Sekundärtext     |
| Dunkelgrau | `#656565` | Text, Flächen    |
| Hintergrund| `#1c1c1c` | Hintergrund      |

```css
:root {
  --orange: #e2671f;
  --gray-light: #7d7d7d;
  --gray-dark: #656565;
  --bg: #1c1c1c;
}
```

## Schriftarten

| Schrift | Schnitte | Verwendung |
|---------|----------|------------|
| [Bebas Neue](https://fonts.google.com/specimen/Bebas+Neue) | Regular | Badge „YouTube on Demand“, Shop-Titel „Boxen“ |
| [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) | 300–800 | Webseite: Fließtext (400), Überschriften (800) |
| [Montserrat](https://fonts.google.com/specimen/Montserrat) | 500–600 | Webseite: einzelne Buttons, Preistabellen, Footer |

Icon-Fonts der Webseite (nicht für Text): Font Awesome 6 Free, themify, et-line, lg (Lightgallery).
